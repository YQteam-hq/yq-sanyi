Usage Examples

Debounce Directive:

<input yq-on:input="handleInput debounce:500" placeholder="Debounced input" >

Throttle Directive:

<button yq-on:click="handleClick throttle:1000" > Click me </button>

Performance Monitoring:

import { EnhancedErrorHandler } from 'yq-sanyi' // Get performance metrics const metrics = EnhancedErrorHandler.getPerformanceMetrics() // Reset metrics EnhancedErrorHandler.resetMetrics()

Template Validation:

import { ValidationUtils } from 'yq-sanyi' const validation = ValidationUtils.validateTemplate(template) if (!validation.valid) { console.log('Errors:', validation.errors) }
