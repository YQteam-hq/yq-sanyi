Scoped styles and CSS variable theming

Both price tags below share one definition, so the framework injects their style once and removes it when the last instance is gone. Everything they paint with comes from --yq-* variables, so the switcher can repaint them without touching component code. Swap the last button to watch the page-level style registry, and open the console to compare yq.scoper.getGlobalStyles() with the component styles in the document.
